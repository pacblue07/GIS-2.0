# GIS 2.0: new site build (prototype)

A static site with no WordPress. To view it, open `index.html` in a browser. It works from this folder, and nothing needs installing.

## What's here (prototype 1, 14 Oct 2026)
The **Buildings** page is map-first, modelled on the Photo Catalog map:
- **Map:** clustered pins coloured by isolation-system family. Click a pin to open the building card.
- **Filters:** search, isolation system, devices, country, use, new or retrofit, structure type and supplemental damping. Each filter shows how many results it would give with the other filters applied.
- **Places list:** country, then city, with counts. Click one to filter.
- **Timeline:** buildings per year. Click a bar for one year, or drag across bars for a range.
- **Results table:** sortable, with a **Download CSV** button for the filtered rows.
- **One result set:** the map, places list, timeline and table always show the same filtered set.

The other menu items (About, Participate, Learn, Resources) are placeholders for the next pass.

## Data
- `data/buildings.js` is generated from `..\database\gis_master_database.json` by `tools/make_data.py`.
- It carries only the fields the 2021 colour key marks for publishing. Engineer, architect, manufacturer and notes are left out until Ian decides (see `..\open-items.md`).
- Locations are city-level. The 53 buildings with no location appear in the table but not on the map.

## Map
- Street tiles come from CARTO, with OpenStreetMap as a fallback, when online.
- `data/world.js` holds Natural Earth country outlines. It shows underneath the tiles, so the map still reads offline.
- Libraries are bundled in `vendor/`: Leaflet 1.9.4 and Leaflet.markercluster 1.5.3, both under BSD/MIT licences. The site does not depend on any CDN.
